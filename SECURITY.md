# Security policy

Momentum keeps all data on your Mac, in its app group container. The only network request it
makes is a book search you type, sent to Open Library.

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/Leeevai/momentum/security/advisories/new)
rather than in a public issue. Include what you found, how to reproduce it, and the version
(Settings → About). You'll get a reply within a week.

## Supported versions

Fixes go into the latest release.
