# Code of conduct

Momentum follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, and assume good intent. Harassment, insults and personal attacks
aren't welcome in issues, pull requests or anywhere else in the project.

If someone's behavior concerns you, report it privately to the maintainer through
[GitHub](https://github.com/Leeevai). Reports are handled confidentially.
